# 原版轨道假名字形

2026-10-06：轨道改用原版 `mf_hiragana_blank/telop`、其 ROMAN SUPPORT / FULL ROMAN 变体及 `mf_katakana_blank/telop`。键盘花瓣继续使用 `fgcharacter`，两者不混用。

逆向证据：`NoteManager::GetNoteCharIdx:`（0x0de28）用 Unicode 减去平假名起始码；`NoteNormal::render`（0x22540）从 `_e_CharPictTbl`（0x139fde）读取纹理编号、x、y，并裁取 78×78。表中あ=(0,0)，ぁ=(390,0)，が=(390,78)，ぱ=(390,390)，っ=(624,546)，ー=(858,0)。字符本身已有原版描边与阴影，浊音／半浊音无需叠加系统字体。

轨道字图三种键盘模式分别使用对应平假名字图；片假名继续使用独立原片假名字图。NFC 归一保证分解浊点／半浊点的字符使用相同预合成字形。ゔ/ヴ取图集中实际的(780,0)，修正旧表错指(0,0)；罕见ゎ/ヮ、ゕ/ヵ、ゖ/ヶ使用原基础字形缩小，避免复制旧表的错误别名字形。当前11首基础谱面所有原始字符均有字图映射。

包装保留8张原图，运行时缓存78×78裁片，不重绘或拉伸字形。可播放音符用telop；灰色补充音符用blank。Crimax颜色遮罩使用同一原图；FAST/LATE与判定文字规则不受影响。
